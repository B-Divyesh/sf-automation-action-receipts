Privacy

Action Receipts is local-first. The CLI does not send telemetry, receipts, commands, paths, outputs, or signing keys anywhere.

Browser verifier

Receipt files and pasted JSON are processed in browser memory and are not uploaded. The site has no advertising, behavioral analytics, third-party fonts, or runtime CDN scripts. A service worker stores public site files on your device so the verifier can work offline.

Local storage

The site stores your theme preference. If you buy or restore the optional Team policy kit, it also stores the license token and the last license verdict under keys beginning with sb_license:automation-action-receipts. You can remove that data with the “Remove license” control or your browser settings.

License verification and checkout

License verification sends the license token to the Sociobot API no more than once per day. If you choose to purchase, checkout opens on Sociobot/Dodo, the merchant of record; their privacy terms apply to information you submit there.

Hosting logs

The static host may process short-lived security and delivery logs such as IP address, requested path, user agent, and timestamp. Action Receipts does not add tracking identifiers.

Your receipts

Receipts may contain sensitive commands, source paths, and output. Use the CLI’s redaction flags before capture and its retention command after the declared window. A signature protects integrity, not confidentiality.

Contact

For privacy questions, open an issue in the project repository without attaching a sensitive receipt.
