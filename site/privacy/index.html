Privacy

Action Receipts works with local receipt files. The CLI does not need an account.

Browser verifier

Selected receipt files and pasted JSON are processed in browser memory. The verifier does not upload them.

Site storage

The site stores a theme choice in this browser. Demo mode uses a separate key that starts with demo:. Reset demo removes that key.

Offline files

A service worker stores public site files on your device after your first visit. This lets the sample verifier reload while offline.

Your receipts

Receipts can contain commands, paths, and output. Redact sensitive values before capture and remove old files with the retention command.

Contact

For privacy questions, open an issue in the project repository. Do not attach a sensitive receipt.
