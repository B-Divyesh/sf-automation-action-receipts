The protocol

A chain reviewers can actually read.

  1. 01

    Declare the boundary

    Record the actor label, authorization reference, intended scope, redaction rules, and retention window before work begins.

  2. 02

    Record real execution

    Wrap a command or append structured tool events. Output is capped, sensitive values are redacted, and artifacts are hashed.

  3. 03

    Seal and carry

    Lock the chain with Ed25519. Export JSON for machines and a self-contained HTML view for incident review.

!
Integrity is not intent.

A valid receipt proves that the signed bundle is unchanged. It does not prove a person's identity, the legitimacy of authorization, or that an action was correct.

Four commands

From open to verified.

TERMINAL / QUICK START
# Build the single binary
$ cargo install --git https://github.com/B-Divyesh/sf-automation-action-receipts

# Declare authority and scope
$ action-receipts new --out deploy.receipt.json \
    --actor "release-bot@ci" \
    --authorization "change-482 approved by ops" \
    --summary "Publish docs" --scope "repo:docs/**"

# Execute, capture, and hash an artifact
$ action-receipts run --receipt deploy.receipt.json \
    --artifact dist/site/index.html -- npm run build

# Seal and verify offline
$ action-receipts seal --receipt deploy.receipt.json \
    --html deploy.receipt.html
$ action-receipts verify deploy.receipt.json --json
